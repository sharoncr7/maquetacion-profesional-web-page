# Reporte de Aprendizajes, Dificultades e Interacción con IA

## 👥 Integrantes y Dinámica de Pair Programming
Al realizar este proyecto de forma individual, se adoptó una metodología de **Pair Programming Híbrida (Humano + Inteligencia Artificial)**:
*   **Sharon (Driver / Conductora):** Responsable de la ejecución técnica, estructuración de archivos locales, maquetación e integración con Git/GitHub.
*   **AI Assistant (Navigator / Navegadora):** Responsable de guiar el diseño estructural, asegurar la semántica HTML5 adecuada y proveer las soluciones CSS responsivas para asemejarse al modelo Pixel Perfect.

---

## 🧠 Aprendizajes Obtenidos
1.  **Estructura Semántica Profesional:** Uso estricto de elementos estructurales nativos de HTML5 como `<nav>`, `<main>`, `<section>` y `<article>` optimizando la legibilidad.
2.  **Estrategias de Diseño con CSS Grid:** Implementación de mallas complejas bidimensionales para organizar las secciones de tarjetas de catálogo en formatos de 4 y 3 columnas de manera limpia.
3.  **Flexbox Eficiente:** Control exacto de alineamientos horizontales usando propiedades como `justify-content: space-between` en las barras de menú superiores.

---

## ⚠️ Dificultades y Soluciones
*   **Maquetación en Tiempos Reducidos:** El reto principal fue la construcción rápida de componentes. Se superó delegando el diseño de las arquitecturas CSS al copiloto de IA mientras se codificaba en paralelo en el editor.
*   **Falta de Compañero Físico:** Se resolvió de manera efectiva mediante un canal continuo de comunicación con la IA, simulando una sesión de desarrollo guiada en tiempo real.

---

## 💬 Bitácora de Interacción con la Inteligencia Artificial (Copiloto)
